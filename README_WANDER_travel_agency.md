# WANDER --- Travel Agency Website

**WANDER** is a travel agency landing-page concept built with HTML and
CSS. Its design invites visitors to explore destinations, compare sample
travel packages, view travel photography, read traveller stories, and
fill out a trip-planning form.

## Features

-   Sticky navigation bar with links to page sections
-   Hero section with a travel-themed background image
-   Introduction section about the travel experience
-   Destination cards for mountain, island, city, and coastal trips
-   Sample travel packages with durations and prices
-   Travel-experience highlights
-   Image gallery
-   Traveller testimonial cards
-   Trip-planning form with name, email, origin, destination, travel
    style, and message fields
-   Footer navigation
-   Responsive layouts for tablet and mobile screens
-   Hover effects, smooth scrolling, CSS Grid, Flexbox, and media
    queries

## Technologies Used

-   HTML5
-   CSS3
-   Images hosted by Unsplash

## Project Files

Keep the HTML and CSS files in the same folder:

``` text
project-folder/
├── 16travelagency.html
└── 16travelagency.css
```

The HTML file links to the stylesheet with:

``` html
<link rel="stylesheet" href="16travelagency.css">
```

If you use different filenames, update the stylesheet link in the HTML
file accordingly.

## How to Run Locally

1.  Download or clone the project files.
2.  Keep `16travelagency.html` and `16travelagency.css` in the same
    folder.
3.  Open `16travelagency.html` in a web browser.

You can also open the project folder in Visual Studio Code and use a
local preview extension.

## Publishing with GitHub Pages

1.  Upload the HTML and CSS files to your GitHub repository.
2.  Open the repository's **Settings → Pages**.
3.  Under **Build and deployment**, choose **Deploy from a branch**.
4.  Select the `main` branch and the `/ (root)` folder, then save.
5.  Wait for the deployment to finish and open the published site link
    shown on the Pages settings screen.

GitHub Pages typically uses a root-level `index.html` as the default
homepage. To make this project the default homepage, rename
`16travelagency.html` to `index.html` and ensure the stylesheet link
still points to `16travelagency.css`. Otherwise, the page may be
available at its individual HTML-file URL.

## Important Notes

-   This is a static front-end demonstration made with HTML and CSS; it
    does not include a booking system or backend.
-   The trip-planning form is a visual form and is not connected to a
    service that receives submissions.
-   Destination details, testimonials, package durations, and prices are
    sample content and should be verified before being used
    commercially.
-   The photos are loaded from external Unsplash URLs, so an internet
    connection is needed to display them.
-   Navigation links move to sections within the same page.
