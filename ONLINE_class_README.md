# Learnora --- Online Learning Platform

Learnora is a responsive online learning dashboard built with HTML and
CSS. It presents a student-friendly learning space with course cards,
progress indicators, weekly activity, categories, and instructor
information.

## Features

-   Sidebar navigation with links to dashboard sections
-   Welcome banner and learning-focused layout
-   Summary cards for enrolled courses, learning hours, and completed
    lessons
-   Course cards with lesson counts, ratings, and progress bars
-   Weekly activity chart and weekly goal indicator
-   Explore-by-category section
-   Instructor list with ratings
-   Responsive layout for desktop, tablet, and mobile screens
-   CSS custom properties, Grid, Flexbox, hover transitions, and media
    queries
-   Google Fonts: DM Sans and Playfair Display

## Project Files

Make sure the HTML and CSS files are in the same folder:

``` text
project-folder/
├── 1onlineclass.html
└── 1onlineclass.css
```

The HTML file links to the stylesheet using:

``` html
<link rel="stylesheet" href="1onlineclass.css">
```

If your HTML file has a different name, keep the CSS file in the same
folder or update the stylesheet path accordingly.

## How to Run Locally

1.  Download or clone this repository.
2.  Keep `1onlineclass.html` and `1onlineclass.css` in the same folder.
3.  Open `1onlineclass.html` in a web browser.

You can also open the folder in Visual Studio Code and use a local
preview extension.

## Technologies Used

-   HTML5
-   CSS3
-   Google Fonts

## Notes

This project is a front-end design/demo. The course details, progress
values, weekly activity, instructor names, and dashboard statistics are
sample content in the page. The interface does not include a backend,
user authentication, or live course-tracking functionality.
